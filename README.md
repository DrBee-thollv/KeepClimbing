# KeepClimbing

Developed with Unreal Engine 5

# Download Git
- Make sure you it includes git bash and select Add to PATH
`https://git-scm.com/`

# Create github account
`https://github.com/`

# Clone Repo
- Open git bash terminal and run following command wherever you want to store this project.
`git clone https://github.com/DrBee-thollv/KeepClimbing.git`

# Open Unreal
- You should be able to open the project in unreal and test it out.
